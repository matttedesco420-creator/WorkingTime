# WorkTime

Zeiterfassung für Projekte (Timer, Einträge, Material, Excel/PDF) als installierbare Web-App.
Alle Daten werden nur lokal auf dem Gerät gespeichert (kein Login, keine Cloud).

## Veröffentlichen (GitHub Pages)
Alle Dateien dieses Ordners ins Repository hochladen (inkl. Ordner `lib/` und `icons/`),
unter Settings → Pages den Branch `main` / Ordner `/ (root)` aktivieren.

## Installieren (Android)
Adresse in Chrome öffnen → Menü (⋮) → „App installieren" (oder Button im Profil).
Nach dem ersten Öffnen läuft die App auch ohne Internet.

## PDF per E-Mail
Übersicht → Projekt wählen → E-Mail-Adresse eingeben → „Per E-Mail".
Auf dem Handy öffnet sich das Teilen-Menü mit angehängtem PDF (z. B. Gmail).
